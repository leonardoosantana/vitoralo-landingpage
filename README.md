# 🏗️ Victor Aló - Arquitetura e Urbanismo (Landing Page)

> Projeto comercial de alta conversão desenvolvido para apresentação de portefólio e captação de leads na área da arquitetura.

https://vitoralo-landingpage-4pja334wp-leonardo-santana.vercel.app/

## 💻 O Projeto
Esta interface web foi estruturada com foco na experiência do utilizador (UX) e no desempenho. O objetivo do negócio era criar uma montra digital limpa e moderna que destacasse os projetos de arquitetura do cliente, facilitando o contacto direto e a prospecção de novos negócios B2B e B2C.

## ✨ Funcionalidades Principais
* **Design 100% Responsivo:** Otimização completa para dispositivos móveis (Mobile-First), garantindo a acessibilidade do portefólio em qualquer ecrã.
* **Foco em Conversão:** Estruturação de botões de *Call to Action* (CTA) estratégicos para maximizar a captação de potenciais clientes.
* **Componentização:** Arquitetura modular que facilita a manutenção e escalabilidade do código.

## 🛠️ Tecnologias Utilizadas
* **React.js:** Construção da interface em componentes reutilizáveis.
* **Vite:** Ferramenta de *build* otimizada para compilação ultra-rápida.
* **Tailwind CSS:** Estilização utilitária para um design consistente e ágil.
* **JavaScript (ES6+):** Lógica de interatividade da página.
